TabView — Help

Tab actions

  • Click a preview or title — jump to that tab
  • Click × on a card — close that tab
  • Drag a card — reorder it in Chrome, or drop it into another window to move it there
  • Drop anywhere in a window — dropping on a window's header or empty space (even a collapsed one) moves the tab to the end of that window
  • Hover (with AI key set) — see a 1-line AI summary of what the tab is about

Selecting tabs

  • Click the checkbox on a card — select it
  • Shift+click anywhere on a card — toggle selection (no need to aim at the checkbox)
  • Hold Shift — all checkboxes become visible across every window
  • Window header checkbox — select every tab in that window
  • Group header checkbox — select every tab in that group

When tabs are selected (bottom bar)

  • Group — create a Chrome tab group from the selection
  • Export to Window — move selection into a brand-new Chrome window
  • Discard — unload from RAM (tab stays, frees memory)
  • Close — close every selected tab

Window actions (each window header)

  • + Add Selected — move currently-selected tabs into this window
  • ⇆ Move Here — pull every tab from another window into the TabView window
  • ⊞ Group All — put every tab in this window into a Chrome tab group
  • ⏸ Pause All — unload every tab from RAM (auto-reloads on visit)
  • × Close All — close every tab in this window
  • Double-click window name — rename the window
  • ▼ — collapse / expand a window

Group actions (each group header)

  • Drag the colored group header — reorder the whole group in the Chrome tab strip, or drop it into another window to move the entire group there
  • Drag a tab onto a group — drop a card onto a group (or onto any card inside it) to move that tab into the group; drag it from one group straight onto another to switch groups
  • Drag a grouped tab onto a loose card — pulls it out of its group
  • ⏸ Pause — unload every tab in the group
  • Ungroup — remove the tabs from the group (keeps them open)
  • Close Group — close every tab in the group

AI features (require an Anthropic API key in Settings)

  • ✨ Auto-Group — Claude proposes 2-7 named groups based on tab topics; you review/edit before applying
  • ✨ Suggest Closes — Claude flags duplicate, stale, or one-off tabs with reasoning
  • ✨ AI toggle on search — type a natural-language query, hit Enter; top matches get a rank badge
  • Hover summaries — 1-line AI summary on hover (cached per tab)

Other controls

  • S / M / L in the top bar — change card size (saved across sessions)
  • Sessions — save your current windows as a named session, restore later
  • Auto-save — TabView snapshots every 2 minutes for crash recovery
  • Auto-refresh previews — when you come back to TabView after N minutes away (configurable in Settings)
  • Merge Windows — collapse every Chrome window into one
  • ↻ Refresh All Captures — re-capture a fresh screenshot of every tab on demand
  • ⚙ Settings — set Anthropic API key and auto-refresh interval

Keyboard shortcuts

  • / — focus the search bar
  • Esc — clear search / close any open modal or panel
  • Shift (hold) — reveal every checkbox, shift+click to select
